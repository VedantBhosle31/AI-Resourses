\hypertarget{linearsvc}{%
\subsection{1. LinearSVC}\label{linearsvc}}

\hypertarget{mental-model}{%
\subsubsection{Mental Model}\label{mental-model}}

Find a linear hyperplane that separates classes with the largest possible geometric margin.

\hypertarget{mathematical-formulation-prediction}{%
\subsubsection{Mathematical Formulation \& Prediction}\label{mathematical-formulation-prediction}}

\textbf{f(x) = w\^{}T * x + b\\
\strut \\
Prediction: y\_hat = +1 if f(x) \textgreater{} 0 else -1}

\hypertarget{optimization-loss-function}{%
\subsubsection{Optimization \& Loss Function}\label{optimization-loss-function}}

min\_\{w,b\} 0.5 * \textbar\textbar w\textbar\textbar² + C * Σ max(0, 1 - y\_i * (w\^{}T * x\_i + b))²\\
\strut \\
The loss term is Squared Hinge Loss (or standard Hinge Loss).

\hypertarget{meaning-breakdown-mental-flowchart}{%
\subsubsection{Meaning Breakdown \& Mental Flowchart}\label{meaning-breakdown-mental-flowchart}}

\begin{quote}
\textbf{\textbar\textbar w\textbar\textbar²\\
↓\\
}Keep boundary simple / maximize geometric margin

\textbf{hinge loss\\
↓\\
}Punish incorrectly classified or insufficiently separated samples

\textbf{C hyperparameter\\
↓\\
}Trade-off between wide margin and classification error
\end{quote}

\hypertarget{sgdclassifier}{%
\subsection{2. SGDClassifier}\label{sgdclassifier}}

\hypertarget{mental-model-1}{%
\subsubsection{Mental Model}\label{mental-model-1}}

Take a small sample or single data point, calculate the prediction error, and instantly update weights via gradient step.

\hypertarget{mathematical-formulation-prediction-1}{%
\subsubsection{Mathematical Formulation \& Prediction}\label{mathematical-formulation-prediction-1}}

\textbf{General Objective: J(w) = (1/n) * Σ L(y\_i, f(x\_i)) + λ * R(w)\\
\strut \\
Single Step Update: w\_\{t+1\} = w\_t - η * ∇J(w\_t)}

\hypertarget{optimization-loss-function-1}{%
\subsubsection{Optimization \& Loss Function}\label{optimization-loss-function-1}}

Configurable loss L(y, f(x)):\\
- L = Hinge (SVM)\\
- L = Log loss (Logistic Regression)\\
- L = Modified Huber (probabilistic SVM)\\
\strut \\
Regularization R(w): L2 norm 0.5*\textbar\textbar w\textbar\textbar², L1 norm \textbar\textbar w\textbar\textbar\_1, or ElasticNet.

\hypertarget{meaning-breakdown-mental-flowchart-1}{%
\subsubsection{Meaning Breakdown \& Mental Flowchart}\label{meaning-breakdown-mental-flowchart-1}}

\begin{quote}
\textbf{prediction\\
↓\\
}Make quick output guess for current sample

\textbf{calculate error\\
↓\\
}Compute loss value L(y\_i, y\_hat\_i)

\textbf{calculate gradient\\
↓\\
}Compute gradient ∇J with respect to weight vector w

\textbf{change weights\\
↓\\
}Update weights w\_\{t+1\} = w\_t - η * ∇J and repeat
\end{quote}

\hypertarget{mlpclassifier}{%
\subsection{3. MLPClassifier}\label{mlpclassifier}}

\hypertarget{mental-model-2}{%
\subsubsection{Mental Model}\label{mental-model-2}}

Stack multiple layers of artificial neurons to learn complex, non-linear feature representations automatically.

\hypertarget{mathematical-formulation-prediction-2}{%
\subsubsection{Mathematical Formulation \& Prediction}\label{mathematical-formulation-prediction-2}}

\textbf{Single Neuron: z = w\^{}T * x + b, Activation: a = f(z)\\
\strut \\
Network Layers: h\_1 = f(W\_1 * x + b\_1), h\_2 = f(W\_2 * h\_1 + b\_2), y\_hat = Softmax(W\_3 * h\_2 + b\_3)\\
\strut \\
Softmax Probability: P(y=k\textbar x) = exp(z\_k) / Σ\_j exp(z\_j)}

\hypertarget{optimization-loss-function-2}{%
\subsubsection{Optimization \& Loss Function}\label{optimization-loss-function-2}}

Cross-Entropy Loss: L = - Σ y\_k * log(y\_hat\_k) + (α / 2n) * Σ \textbar\textbar W\_l\textbar\textbar\_F²\\
\strut \\
Training uses Backpropagation + Gradient Descent (Adam, L-BFGS, or SGD).

\hypertarget{meaning-breakdown-mental-flowchart-2}{%
\subsubsection{Meaning Breakdown \& Mental Flowchart}\label{meaning-breakdown-mental-flowchart-2}}

\begin{quote}
\textbf{input layer\\
↓\\
}Receive raw input feature vector x

\textbf{hidden layers\\
↓\\
}Extract non-linear hierarchical feature embeddings

\textbf{softmax output\\
↓\\
}Produce normalized probability distribution across classes

\textbf{backprop\\
↓\\
}Propagate gradient error backwards to update weight matrices W\_l
\end{quote}

\hypertarget{perceptron}{%
\subsection{4. Perceptron}\label{perceptron}}

\hypertarget{mental-model-3}{%
\subsubsection{Mental Model}\label{mental-model-3}}

A single linear neuron that tests predictions and shifts its boundary weights only when it makes a mistake.

\hypertarget{mathematical-formulation-prediction-3}{%
\subsubsection{Mathematical Formulation \& Prediction}\label{mathematical-formulation-prediction-3}}

\textbf{Prediction: y\_hat = sgn(w\^{}T * x + b)\\
\strut \\
Condition to update: If y\_i * (w\^{}T * x\_i + b) ≤ 0 (Misclassified)}

\hypertarget{optimization-loss-function-3}{%
\subsubsection{Optimization \& Loss Function}\label{optimization-loss-function-3}}

Update Rule:\\
w ← w + η * y\_i * x\_i\\
b ← b + η * y\_i

\hypertarget{meaning-breakdown-mental-flowchart-3}{%
\subsubsection{Meaning Breakdown \& Mental Flowchart}\label{meaning-breakdown-mental-flowchart-3}}

\begin{quote}
\textbf{correct prediction\\
↓\\
}Do nothing (weights stay unchanged)

\textbf{misclassified sample\\
↓\\
}Shift weight vector w in the direction of the error y\_i * x\_i

\textbf{simple loop\\
↓\\
}Iterate until linear convergence or max iterations reached
\end{quote}

\hypertarget{logisticregression}{%
\subsection{5. LogisticRegression}\label{logisticregression}}

\hypertarget{mental-model-4}{%
\subsubsection{Mental Model}\label{mental-model-4}}

Compute a linear score for a sample, then map it through a Sigmoid curve to output a clean class probability between 0 and 1.

\hypertarget{mathematical-formulation-prediction-4}{%
\subsubsection{Mathematical Formulation \& Prediction}\label{mathematical-formulation-prediction-4}}

\textbf{Linear Score: z = w\^{}T * x + b\\
\strut \\
Sigmoid Function: P(y=1\textbar x) = σ(z) = 1 / (1 + exp(-z))}

\hypertarget{optimization-loss-function-4}{%
\subsubsection{Optimization \& Loss Function}\label{optimization-loss-function-4}}

Binary Cross-Entropy Loss:\\
L(w) = - (1/n) * Σ {[} y\_i * log(p\_i) + (1 - y\_i) * log(1 - p\_i) {]} + (1 / 2C) * \textbar\textbar w\textbar\textbar²\\
\strut \\
Optimized via L-BFGS, Newton-CG, or Liblinear.

\hypertarget{meaning-breakdown-mental-flowchart-4}{%

↓\\

↓\\

\end{quote}

\subsubsection{Mental Model}\label{mental-model-59}}

\hypertarget{mathematical-formulation-prediction-59}{%

\hypertarget{stationarity}{%
\subsection{6.4 Stationarity}\label{stationarity}}

A stationary time series has statistical properties that do not systematically
change over time. In weak stationarity, the mean and variance are constant
and covariance depends primarily on the lag rather than the absolute time:

\[
\mathbb{E}[y_t] = \mu
\]

\[
\text{Var}(y_t) = \sigma^2
\]

\[
\text{Cov}(y_t,y_{t-k}) = \gamma_k
\]

Stationarity is especially important for ARIMA-type models.

\hypertarget{differencing}{%
\subsubsection{Differencing}\label{differencing}}

First-order differencing is defined as:

\[
\Delta y_t = y_t-y_{t-1}
\]

Second-order differencing is:

\[
\Delta^2 y_t = \Delta y_t-\Delta y_{t-1}
\]

Differencing removes trend-like non-stationarity.

\hypertarget{seasonal-differencing}{%
\subsubsection{Seasonal Differencing}\label{seasonal-differencing}}

For seasonal period $s$:

\[
\Delta_s y_t = y_t-y_{t-s}
\]

This is useful when a series contains repeating seasonal patterns.

\hypertarget{granger-causality}{%
\subsection{6.22 Granger Causality}\label{granger-causality}}

Granger causality tests whether historical values of one variable provide
useful predictive information for another variable.

If $X$ helps predict $Y$ beyond the information contained in the historical
values of $Y$, then $X$ is said to Granger-cause $Y$:

\[
Y_t = \sum_i a_i Y_{t-i} + \sum_j b_j X_{t-j} + \epsilon_t
\]

A significant contribution from the $X$ terms suggests predictive causality,
but it should not be interpreted as proof of real-world causal mechanisms.

\hypertarget{cointegration}{%
\subsection{6.23 Cointegration}\label{cointegration}}

Two non-stationary series may have a stationary linear combination. Such
series are said to be cointegrated:

\[
z_t = y_t-\beta x_t
\]

If $y_t$ and $x_t$ are individually non-stationary but $z_t$ is stationary,
the variables may share a long-run equilibrium relationship.

\hypertarget{time-series-leakage}{%
\subsection{6.35 Time Series Leakage}\label{time-series-leakage}}

Temporal leakage occurs when information that would not have been available at
prediction time is used during training.

Common examples include:

\begin{itemize}
\item Randomly shuffling time-series observations before splitting.
\item Computing rolling statistics using future observations.
\item Scaling the complete dataset before creating a chronological split.
\item Using future target values to construct features.
\item Performing interpolation using observations from the future.
\end{itemize}

The fundamental rule is:

\[
\boxed{\text{Features at time }t\text{ must only use information available at or before }t}
\]

\hypertarget{key-time-series-concepts-to-remember}{%
\subsection{6.39 Key Time Series Concepts to Remember}\label{key-time-series-concepts-to-remember}}

\begin{itemize}
\item \textbf{Trend} describes long-term direction.
\item \textbf{Seasonality} describes repeating fixed-period behavior.
\item \textbf{Stationarity} means the statistical behavior of the series is stable through time.
\item \textbf{ACF} measures correlation with lagged observations.
\item \textbf{PACF} measures direct lag relationships after accounting for intermediate lags.
\item \textbf{AR} models depend on previous observations.
\item \textbf{MA} models depend on previous forecast errors.
\item \textbf{ARIMA} combines autoregression, differencing, and moving average.
\item \textbf{SARIMA} adds explicit seasonal components to ARIMA.
\item \textbf{ETS/Holt-Winters} models level, trend, and seasonality through exponential smoothing.
\item \textbf{VAR} models multiple interacting time series.
\item \textbf{GARCH} models changing conditional variance.
\item \textbf{Granger causality} concerns predictive usefulness, not proof of true causation.
\item \textbf{Cointegration} describes long-run equilibrium relationships between non-stationary series.
\item \textbf{Walk-forward validation} preserves the temporal structure of the forecasting problem.
\item \textbf{Data leakage} occurs when future information enters the training process.
\item \textbf{Residuals should ideally resemble white noise} after a good forecasting model has captured the systematic structure.
\end{itemize}
